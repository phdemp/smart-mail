## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DB → HTML template (llm_logs) | llmLog.provider (text) and llmLog.latency_ms (integer) flow from llm_logs into the rendered HTML |
| DB → HTML template (urgency_reason) | cls.urgency_reason flows from classifications into title attribute of urgency badge |
| Client → draftEditor state | User clicks trigger Reply button and tone chips — state changes are local to Alpine component, no server interaction until changeTone() fires POST |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Injection (XSS) | urgency tooltip — title="${escHtml(cls.urgency_reason)}" | mitigate | escHtml() wraps urgency_reason before embedding in title attribute. This is enforced in EDIT 3 of Task 1. escHtml() encodes double-quotes which would break out of the title attribute. |
| T-05-03-02 | Injection (XSS) | attribution footer — llmLog.provider in HTML | mitigate | escHtml(llmLog.provider) wraps provider name before embedding in div. Provider name comes from llm_logs table (set by router.js) but must be treated as untrusted. |
| T-05-03-03 | Injection (XSS) | attribution footer — llmLog.latency_ms | accept | latency_ms is an INTEGER column in llm_logs (set by router.js as a numeric value). Integer columns cannot contain script. Rendering as ${llmLog.latency_ms} directly is safe — no escHtml needed. |
| T-05-03-04 | Elevation of Privilege | renderActionZone() draft trigger | accept | The updated onclick triggers .draft-reply-trigger click (a DOM element within the same email-detail context). No auth or privilege boundary crossed — purely UI state change within the same authenticated session. |
| T-05-03-05 | Denial of Service | init() auto-regen removed | mitigate | Removing init() auto-regen eliminates the risk of generating a draft API call on every email open. This reduces API quota consumption and removes a latency hit per email view. The mitigation is the removal itself (D-13). |
| T-05-03-06 | Injection (XSS) | draftEditor() skipAI() — state mutation only | accept | skipAI() only mutates local Alpine reactive state (draftBody='', source='user', skipMode=true). No server calls, no DOM injection. No attack surface. |
</threat_model>
