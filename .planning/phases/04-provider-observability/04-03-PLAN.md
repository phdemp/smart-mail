## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server → settings.html health panel | server-rendered Alpine data; last_error_msg passed through Alpine x-text (not x-html) — automatic XSS encoding |
| server → dashboard pill HTML fragment | server renders the full amber pill HTML; no user-controlled content in the fragment — only static copy "AI features degraded" |
| HTMX → /api/llm/health/pill | Authenticated request (global requireAuth covers it); response is static HTML, no dynamic content |

Verified: no x-html bindings in health panel (V5 ASVS L1) |
| T-04-03-02 | Information Disclosure | dashboard pill HTML fragment | mitigate | Pill HTML is static — only "AI features degraded" copy; no provider names, no error details, no user data in the fragment. Language boundary is enforced server-side in api.js (Plan 02) |
| T-04-03-03 | Tampering | HTMX poll target | accept | /api/llm/health/pill is auth-guarded by global middleware; HTMX sends the session cookie automatically; CSRF is low-risk for a GET request that returns read-only HTML |
